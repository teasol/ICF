## 2026-09-04 — §219: SH 강화 7종, 가설 3건 반증, SHJ가 Oracle 최초 이동

7종 변형을 **한 실행**(949초)에 별도 마진으로 내보냈습니다. 전 과제 fold-mean이 기준선과 일치해 오염이 없습니다. 연구 지표는 **Oracle 상한 이동**으로 교체했습니다(macro는 1%p 미만을 분해 못 함).

### 반증된 가설 3건 — 전부 제가 세운 것입니다
1. **"차원을 늘리면 나아진다"(32→256)** — 반증. SH2가 SH보다 나쁩니다(macro −0.0045). 형상통계도 상위 차원에 정보가 집중되어 있습니다.
2. **"추정 노이즈가 병목"** — 반증. Bowley/Moors 로버스트 통계가 3·4차 모멘트보다 나쁩니다(SHR −0.0029 vs SH +0.0029). 분산을 줄인 대가로 정보를 더 잃었습니다.
3. **"왜도와 첨도가 상보적"** — 반증. SHS·SHK·SH가 모두 +0.0024~+0.0029로 동일합니다. 두 반쪽은 상보가 아니라 **서로 중복**입니다.

### SHJ — 프로젝트 최초의 Oracle 이동
결합(다변량) 형상: 슬라이드 자신의 평균·공분산으로 백색화한 뒤 **반경 분포의 형상**(8D).
- **ARID1A `0.6363`으로 기존 최상 브랜치 DS(`0.6193`)를 넘었습니다.** Oracle `0.6565` → `0.6589`.
- **잡음 아님**: 50 fold 중 **48개**가 0.5 초과(p = 1.1e-12), 표준편차 0.0931로 DS(0.1355)보다 작습니다.
- **거의 독립**: ARID1A에서 모든 기존 브랜치와 |r| ≤ 0.132 (전 과제 최대 0.227, 후보 중 최저).
- ARID1A 앙상블: CV+BD+DS `0.6842` → +SHJ **`0.7021`**.

### 그러나 게이트 ② 불통과 — 사전 선언 규칙상 기각
SHJ는 KRAS `0.4823`, Prog `0.4889`, PBRM1 `0.4797`로 **3개 과제에서 우연 이하**(단독>0.5가 4/7)이며, §218에서 사전 선언한 게이트 ②를 통과하지 못합니다. 앙상블 macro도 뒷받침하지 않습니다(5-branch+SHJ 0.6202 / 3/7, CV+BD+DS+SHJ 0.6265로 SHJ 없는 0.6274보다 낮음).

**판정: SHJ 기각, 채택·승격 없음.** SH 축은 닫지 않습니다(Oracle이 움직였으므로 중단 규칙 미발동).

### 게이트 ②의 설계 결함 — 기록만, 수정 안 함
게이트 ②는 **"어디에도 정보 없음"(BS)** 과 **"정보가 특정 과제에 집중"(SHJ)** 을 구분하지 못합니다. SHJ는 ARID1A에서 최상 브랜치이므로 무정보가 아닙니다.

**결과를 본 뒤 사전 선언 기준을 완화하는 것은 §214의 실패 양식 그 자체이므로 본 세션에서 게이트를 수정하지 않았습니다.** 개정 여부는 사용자 판단 사항입니다.
