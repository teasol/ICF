# RU-85 — Tier 1 3건(AKS·MDX·LID) 라벨 무관 게이트 ① 종료 보고

2026-09-07 · 유형 `diagnostic` (전체가 탐색적) · 실행 `ru85_stageA` / `ru85_stageB` · **hold-out 미검증**

## 1. 결론과 운영 결정

**세 후보 중 둘(AKS·LID)이 제안서가 스스로 선언한 라벨 무관 조기 사망 조건에 걸려 성능 조회 전에
종료됐다. 생존한 MDX는 게이트 ① 직교성을 통과했다 — max |r| = 0.267, 랭크 효율 45% → 49%.**

다만 게이트 ① 통과 후 기록한 성능은 **MDX 단독 AUROC가 7과제 중 5과제에서 0.5 미만**이다.
`H3`이 위험으로 예측한 **"직교하나 무정보"**(§218 `BS` 유형) 패턴과 일치한다. 정보량 판정은
게이트 ②의 몫이며 이 RU는 그것을 판정하지 않는다.

**운영 결정:** MDX를 채택 후보로 기록하고 게이트 ② 심사를 별도 RU로 넘긴다. AKS·LID는 각자의
사망 조건과 함께 기록하고, 하위축을 닫을지는 [`closed_axes.md` §3](../closed_axes.md)에 올려
사용자 판정을 받는다. **축을 자동으로 닫지 않는다.**

## 2. 단계 A — 라벨 무관 조기 사망 조건

`cptac_luad/KRAS_mutation` 50 fold, query 슬라이드-fold 쌍 3,061개. 과제는 후보 선호가 아니라
**Primary 7 중 context 슬라이드 수가 가장 많아(240~261장) "전체 슬라이드의 x% 이상" 형태의 판정이
가장 안정적**이라는 이유로 사전 고정했다. 임계는 전부 제안서 원문이다.

| 후보 | 조건 | 임계 | 실측 | 판정 |
|---|---|---|---|---|
| **AKS** | 각도 스펙트럼 엔트로피 `H_q > 0.99`인 슬라이드 비율 | ≥ 0.90 | **1.000** | **사망** |
| | 그리고 `H_q`의 슬라이드 간 표준편차 | < 0.01 | **0.0017** | |
| | (부수) `\|r\|(m_akd, m_akf)` — 8D 중복 여부 | > 0.9면 4D 축소 | 0.651 | 중복 아님 |
| **MDX** | `b = 0.25`에서 단봉(K=1) 쌍 비율 | ≥ 0.95 | 0.818 | 통과 |
| | 계곡 깊이의 슬라이드 간 표준편차 | < 0.02 | 0.2403 | 통과 |
| | 격자 대조군 `\|r\|(G=257, G=129)` | < 0.9 | 0.953 | 통과 |
| | (부수) 고윳값 인접비 < 1.01 발생률 | > 0.05면 4방향 강등 | 0.0015 | 강등 불필요 |
| **LID** | `ID_TwoNN`의 슬라이드 간 표준편차 | < 0.2 | 1.285 | 통과 |
| | `\|ID₂₀ − ID₅\| < 0.3`인 슬라이드 비율 | ≥ 0.95 | 0.000 | 통과 |
| | 부분추출 `\|r\|(m=4096, m=1024)` | < 0.8 | **0.314** | **사망** |
| | (부수) 크기 대리변수화 `\|r\|(m_lid, log N)` | > 0.5 | 0.051 | 해당 없음 |

**AKS의 사망은 기전 수준의 관측이다.** 백색화 후 32D에서 UNI2 토큰 구름의 각도 산포는
`H_q` 평균 0.9963·표준편차 0.0017로 **사실상 등방**이다. 각도 자유도에 슬라이드 간 변별 정보가
없다. 이것은 AKS 구현의 결함이 아니라 표현공간의 성질이다.

**LID의 사망은 추정기의 표본 민감성이다.** 개념이 아니라 계측이 죽었다 — `ID_TwoNN`의 슬라이드 간
분산은 충분하고(1.285) 다중 스케일 구조도 있으며(평탄 비율 0.000), **agy가 지적한 토큰 수 대리
변수화도 발생하지 않았다**(`|r|(m_lid, log N) = 0.051`). 마진이 부분추출 크기에 흔들린 것이 원인이다.
이는 착수 전 합성 데이터 측정에서 예고됐던 성질이다 — 군집 구름에서는 안정적이나 국소 선형에서는
k-NN 거리비가 1로 붕괴해 `ID = 1/mean(log ratio)`가 주변 차원 32를 한 자릿수 넘게 초과했다.

## 3. 단계 B — 게이트 ① 직교성 (MDX)

Primary 7 전량 50 fold. 기준 집합은 공식 5-branch와 **채택된 `SH`·`SHJ`를 모두 포함**한다.

| Grade | −0.011 | −0.057 | 0.061 | −0.047 | −0.068 | −0.062 | 0.028 | 0.068 |
| KEAP1 | −0.023 | 0.029 | 0.080 | 0.047 | 0.059 | 0.034 | 0.051 | 0.080 |

**max \|r\| = 0.267** (기각선 0.6). 참고로 `SH`는 채택 시 0.418, `SHJ`는 0.227이었다.
**랭크 효율 2.26/5 → 2.96/6, 45% → 49%** 로 상승했다(6-branch 통과선 eff.rank ≥ 2.72).
두 조건을 모두 만족해 **게이트 ① 통과**다.

sign agreement 3/7. **이 표는 기록용이며 승격이나 채택 판정에 쓰지 않는다** — 절대 macro는 과제
군집 SE가 크고, 승격은 `PROJECT.md` §4의 대응 per-fold Δ 구간으로 판정한다.

**단독 AUROC가 5/7 과제에서 0.5 미만이다.** 게이트 ②a(전 과제 단독 > 0.5)를 그대로 적용하면
통과하지 못하는 값이나, **게이트 ② 판정은 이 RU의 범위가 아니다.**

**사전 등록이 어긋났다.** MDX는 게이트 ②b 1순위로 `Grade`를 지목했는데(BD만 0.4665로 우연 이하인
과제라 모드 구조가 남은 후보라는 논거였다) 실측에서 Grade가 **7과제 중 최저 0.4270**이고,
지목하지 않은 `KRAS`가 최고 0.5826이다. 사후에 KRAS를 새 1순위로 바꾸지 않는다 — 사전 등록의
실패로 기록한다.

## 4. 사전 가설 판정

- **H1 (세 후보 모두 퇴화하지 않는다) — `반박`.** 3건 중 2건이 사망했다.
- **H2 (AKS가 게이트 ①을 통과한다) — `판정 불가`.** 등방성으로 먼저 죽어 게이트 ①에 도달하지
  못했다. **구조적 보장은 실제로 성립했다** — 합성 검증에서 구면대칭 구름에서 AKS 8D가 항등적으로
  상수(엔트로피 0.9999, 이방성 0.0042)임을 확인했다. 문제는 그 보장이 **실제 데이터가 바로 그
  구면대칭에 가깝다**는 것을 뜻했다는 점이다. 직교성 논거가 곧 무정보성 논거였다.
- **H3 (MDX·LID는 데이터 조건부) — `지지`.** MDX는 게이트 ①을 통과하고도 단독 AUROC가 5/7에서
  0.5 미만이어서 예측한 "직교하나 무정보" 유형에 해당한다. LID는 예측한 두 위험 중
  **부분추출 비강건으로 죽었고 크기 대리변수화는 발생하지 않았다.**

  일치했다(7과제 × 50 fold). 후보 마진이 앙상블에 개입하지 않았음의 확인이다.

  단계 B wall 1,207초, 7과제를 7 GPU 병렬(MDX만). 예산 상한 2 GPU-h 이내다.
  **LID 비용 신고에 붙었던 두 채점자의 명시적 불신은 해소됐다.**

## 6. 계획 이탈 — 구현 단계에서 사양 결함 2건

세 건 모두 **실제 데이터·라벨 열람 전**에 카드에 기록했고 판정 기준·사망 조건·마진 목록은 바꾸지 않았다.

1. **MDX 봉우리 규칙에 prominence 하한이 없었다.** 합성 단봉 가우시안에서 꼬리 잡음 봉우리(전역
   최대의 0.4~0.6% 높이)가 두 번째 봉우리로 선택되어 계곡 깊이가 **0.811**까지 올라갔다 — 단봉
   구름에서 깊은 계곡을 보고하고 있었다. 고정 상수 `_PEAK_FLOOR = 0.05`를 도입했다. 수정 후
   합성 검증에서 **제안서의 핵심 논거가 재현됐다** — 균등분포 0.033 대 이봉 0.587로, 둘 다 초과첨도
   ≈ −1.2라 `SH`·`SHJ`로는 구분되지 않는 쌍이다.
2. **AKS 8D의 구성이 모호했다.** 제안서가 5개 이름으로 8차원을 서술해 개수가 맞지 않았다.
   **조건수를 제외**하고 스펙트럼당 4개(엔트로피·최대값·participation ratio·이방성)로 확정했다.
   제안서 자신이 `log(q_max/q_min)`의 상계 부재를 지적했고, 제외하면 8개 특징 전부가 [0,1]에 든다.
3. **LID의 안정성 한계를 사전 기록했다.** 위 §2의 합성 측정이다.

## 7. 남은 한계와 후속

- **AKS·LID의 사망은 이 구성에서의 사망이다.** 다른 대역폭·다른 추정기·다른 부분추출 규칙에서
  같은 결론이 나오는지는 미검증이다. 형상 계열 일반의 불가능으로 확대하지 않는다.
- **LID의 8개 특징별 `log N` 상관은 측정하지 않았다.** 마진 수준(0.051)과 `ID_TwoNN`(0.425)만
  기록했다. 제안서의 falsifier 5는 특징별 제거 규칙이었으나 특징을 저장하지 않아 실행할 수 없었다.
- MDX의 **게이트 ②(정보량) 심사가 다음 단계**다. 단독 AUROC 5/7 미달과 사전 등록 실패를 함께
  가져간다. **3건이 동일 에이전트 한 배치 산출이며 독립 비교군이 없다는 결손은 그대로 남는다.**
