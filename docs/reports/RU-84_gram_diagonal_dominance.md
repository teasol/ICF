# RU-84 — RBF Gram 대각 지배의 현행 규모 실측 종료 보고

2026-09-07 · 유형 `reproduction_measurement` · 출처 `ru81_reg_20260907_r1` 저장 geometry · GPU 0

## 1. 결론

**§199가 `CA-04`의 기각 기전으로 제시한 "RBF Gram이 대각선 근처만 1이고 나머지는 0에 수렴한다"는
`반박`됐다.** 현행 구현에서는 반대다 — off-diagonal이 대각을 압도한다.

판정 대상 1,050개 (fold × 브랜치) 중 대각 지배가 성립할 수 있는 경우는 **0건**이다.

## 2. 왜 그런가 — 대역폭과 표준화가 결정한다

두 가지 사실이 결합한다. 둘 다 코드에서 확인했다.

1. `solvers.solve_kernel_ridge`는 커널을 씌우기 **전에** context 통계로 피처별 표준화를 한다
   (`ctx_std = (ctx_feats − mean) / std`). 따라서 각 차원의 분산이 1이다.
2. `solvers.kernel_matrix`의 기본 대역폭은 `gamma = 1/dims`다. `config.krr_gamma`의 기본값이
   `None`이고, §199 실험 스크립트(`scripts/analysis/kernel_ridge_probe.py`)도 gamma를 넘기지 않는다.

표준화의 귀결로 쌍거리의 평균은 `E‖x_i − x_j‖² = 2d`이며, **차원·상관 구조와 무관하게 정확히
성립**한다(각 차원의 분산이 1이므로 차원별로 2를 더한 것이다). 여기에 `gamma = 1/d`를 곱하면

```
E[ gamma · ‖x_i − x_j‖² ] = 2      (차원·상관·N_ctx와 무관)
```

이고, `exp(−z)`가 볼록하므로 Jensen에 의해

```
평균 off-diagonal 커널 ≥ exp(−2) = 0.1353
행별 off-diagonal 합 ≥ (N_ctx − 1) × 0.1353
```

대각은 정확히 1이다. 대각 지배가 성립하려면 행 합이 1보다 작아야 하므로 `N_ctx ≤ 8`이어야 한다.

## 3. 실측 — 저장 geometry로 전제를 독립 확인

`trace = Σ eigenvalues`에서 클래스 균형 분산 `v = trace/2`를 얻고 `rho_std = v / dimension`으로
표준화 전제를 확인했다. `rho_std ≈ 1`이면 위 논거의 전제가 실제로 성립한다는 뜻이다.

| 브랜치 | 차원 | `N_ctx` 범위 | `rho_std` 평균 | off-diag 커널 하한 평균 | 행 합 하한 (평균 / 최소) | 대각 지배 가능 fold |
|---|---:|---|---:|---:|---:|---:|
| BM | 32 | 90–261 | 0.9905 | 0.1380 | 28.6 / 11.3 | **0** |
| QA | 128 | 90–261 | 0.9924 | 0.1377 | 28.6 / 11.3 | **0** |
| DS | 32 | 90–261 | 0.9918 | 0.1378 | 28.6 / 11.3 | **0** |
| CV *(판정 제외)* | 32640 | 90–261 | 0.9696 | 0.1451 | 30.4 / 11.6 | 0 |

`rho_std`는 판정 대상 3개 브랜치 모두 사전 허용 범위 `[0.5, 2.0]` 안이고 1에 매우 가깝다.
**최악의 fold에서도 행 합 하한이 11.2**로 대각(1)의 11배다.

### 사전 가설 판정

- **H1 (대각 지배 불성립) — `지지`.** 350 folds × 3 브랜치 = 1,050건 전부에서 `S_lo > 1`이다.
- **H2 (`N_ctx = 40`에서도 성립) — `지지`.** `39 × exp(−2) = 5.28 > 1`이다.
  **기전 주장의 오류는 표본 수 전제와 무관하다** — 문서의 `N_ctx ≈ 40`이 옳았더라도 결론은 같다.

## 4. 이 결과가 말하지 않는 것

- **§199의 성능 하락을 설명하지 않는다.** `0.6265 → 0.6125`는 실측이고 이 RU는 그 원인을 다루지
  않았다. 하락의 기전은 여전히 **`미확인`** 이다. 대각 지배가 아니라는 것이 "비선형 커널이
  잘 작동한다"는 뜻은 전혀 아니다.
- **cosine·poly 커널은 측정하지 않았다.** 저장 고유값으로 판정할 수 없어 범위에서 제외했다.
  `CA-04`의 경계는 RBF에 한정되지 않으므로 cosine은 미검증으로 남는다.
- **CV는 판정에서 제외했다.** 정규화 경로가 `_normalize_descriptors`로 달라 전제가 같은지
  확인하지 않았다. 다만 실측 `rho_std = 0.9696`으로 같은 결론 방향이다.
- 이 측정은 **Gram의 구조**만 다룬다. 과적합 여부는 별개이며 측정하지 않았다.

## 5. 실행 유효성

- 저장 geometry 350 folds 전량, 결측·비유한 값 0건. `rho_std` 사전 허용 범위 통과.
- 예산: **GPU 0**, wall 0.51초. 새 특징 추출·새 fold·hold-out 접근 없음.
- 계획 이탈 없음. 사전 선언한 범위(BM·QA·DS 판정, CV 보고, cosine 제외)를 지켰다.
- **한계**: `E‖x_i − x_j‖² = 2v`에서 `v`는 클래스 가중 분산이다. solver의 표준화는 비가중이므로
  비가중 쌍거리 평균은 정확히 `2d`이고, `rho_std`는 그 전제의 독립 확인 역할이다.
