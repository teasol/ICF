# 닫힌 축 레지스트리 (Closed Axes Registry) — 정본

> **이 파일은 "다시 열지 않는 연구 축"의 단일 출처(SSOT)다.**
> 다른 문서는 축을 재서술하지 않고 이 파일의 축 ID를 인용한다.
>
> **왜 이 파일이 필요한가.** §226 다중 에이전트 라운드에서 세 벤더의 `fatal` 판정이 3건
> 엇갈렸고, **세 건 모두 원인이 "축이 닫힌 것은 아는데 경계가 어디까지인지 문서에 없다"**
> 였다. `research_directions.md`가 직접 기록한다 — *"이 경계를 명문화하지 않으면 향후 동종
> 제안마다 같은 불일치가 반복된다."* 따라서 모든 축은 **경계 안 / 경계 밖**을 함께 적는다.

**Last updated**: `2026-09-06`

---

## 0. 레지스트리 사용 규칙

1. **축을 닫을 때**: 아래 표에 행을 추가하고 §2에 상세 항목을 만든다. 필수 필드는
   `기각 기전`, `경계 안(저촉)`, `경계 밖(비저촉)`, `재개 조건` 네 가지다. 넷 중 하나라도
   비어 있으면 축을 닫은 것으로 인정하지 않는다.
2. **축을 다시 열 때**: 임의로 열 수 없다. `재개 조건`이 충족됐거나 **사용자의 명시적 해제
   결정**이 있어야 하며, 해제는 [`decisions.md`](decisions.md)에 결정 레코드로 남긴다.
3. **제안을 심사할 때**: `경계 안`에 해당하면 성능·점수와 무관하게 기각한다.
   `경계 밖`이면 저촉을 사유로 기각하지 않는다. **판단이 갈리면 §3의 미확정 목록으로 올리고,
   심사자가 임의로 한쪽을 채택하지 않는다.**
4. **상태 값**: `CLOSED`(닫힘) · `REOPENED`(철회되어 열림) · `경계 미확정`(축은 닫혔으나
   경계 판정이 필요함).

## 2. 축별 상세

### `CA-01` 합성 데이터 분포 정렬 — §129

- **기각 기전**: 합성 에피소드를 실제 UNI2 통계에 맞출수록 성능이 **단조로 악화**했다
  (v102 t=−2.70 기각, v100 t=−3.59 기각). 격차를 닫는 것이 도움이 되지 않을 뿐 아니라
  방향이 반대였다.
- **경계 안(저촉)**: 실제 임베딩 통계(모멘트·공분산·꼬리)를 목표로 합성 생성기를 조정하는 모든 시도.
- **경계 밖(비저촉)**: 합성 데이터를 **회귀 테스트·불변식 검증용**으로 쓰는 것. 성능 주장을
  하지 않는 한 저촉이 아니다.
- **재개 조건**: 임베딩 백본이 UNI2에서 교체되는 경우.

### `CA-02` DD 브랜치 부활 — §147 · §195

- **기각 기전**: selector로서 |λ|와 |t| 어느 쪽도 |λ| 단독을 넘지 못했다. §195의 오프라인
  재집계에서도 DD 포함 구성이 이득을 내지 못해 §198에서 제거됐다.
- **경계 안(저촉)**: DD(2차형식 판별 거리) 마진을 앙상블 구성원으로 되돌리는 모든 제안.
  잔차 게이트·적응적 rank 등 명칭이 달라도 DD 마진을 되살리면 저촉이다.
- **경계 밖(비저촉)**: `src/models/dd_adaptive_rank.py`가 제공하는 **BD ordered-typicality
  마진**. BD는 정식 브랜치이며 DD와 별개다.
- **재개 조건**: **사용자의 명시적 Closed Axis 해제 결정.** §226에서 `P1-RESIDUAL-GATE`가
  예비 재집계 `+1.29%p / 5/7`을 제시했으나 `미검증`이며, 점수와 무관하게 절차상 기각을 유지했다.

### `CA-03` CT 세포 표본 수 확대 — §159

- **기각 기전**: 64-cell 상한을 제거해도 개선이 없었다. 샘플링은 병목이 아니었다.
- **경계 안(저촉)**: `cells_per_bag` 확대로 CT 성능을 올리려는 시도.
- **경계 밖(비저촉)**: 토큰 수(`CT tokens`)·사전 구성 방식·readout 변경.
  이들은 §158·§161에서 별도로 다뤄졌다.
- **재개 조건**: CT가 공식 비교 기준에 복귀하는 경우 (현재 CT는 비용 대비 기여 미확인으로
  §214-V 이후 비교 기준에서 제외되어 있다 — [`PROJECT.md` §3.2](PROJECT.md) 참조).

### `CA-04` 슬라이드 수준 비선형 커널 readout — §199

- **기각 기전**: `N_ctx ≈ 40`을 사실상 무한차원 RKHS로 보내면 Gram 행렬이 대각 지배가 되어
  **40개 표본의 국소 잡음을 암기**한다. 실측 Primary 7 macro `0.6265 → 0.6125`
  (−0.0140), ARID1A는 +0.1142인데 SMAD4가 −0.1157로 우연 이하(0.4290)까지 붕괴했다.
  선형+RBF 앙상블 `0.6271`은 50-fold 표준오차(±0.015) 안의 허상이다.
- **경계 안(저촉)**: 슬라이드 수준에서 **이미 32차원으로 압축된 디스크립터**에 RBF·Cosine 등
  범용 비선형 커널을 씌워 **선형 Ridge readout을 대체**하는 것. §199의 결론은
  *"Readout 단은 선형 Ridge 체제를 유지해야 함"*이다.
- **경계 밖(비저촉)**: **선형 그람 행렬만 쓰는 통합**. §226에서 `QJF`가 이 근거로 비저촉 판정을 받았다.
- **재개 조건**: `N_ctx`가 수백 규모로 커져 Gram 대각 지배가 해소되는 벤치마크가 도입되는 경우.
  (기각 기전이 `N_ctx ≈ 40`이라는 표본 수에 직접 걸려 있다.)
- **경계 미확정 → §3-D 참조**: 유한차원 다항 커널(`LSAK`의 `K_int = K̃_L ⊙ K̃_S`, 2차 다항)이
  저촉인지.

### `CA-05` 원천 패치 직접 우도비 · Top-K MIL — §200

- **기각 기전**: 패치 간 내적을 직접 계산하면 **특정 Context 슬라이드의 염색 톤·배경 노이즈가
  우연히 일치하는 패치**가 상위 K로 오선별된다. LR 단독 macro `0.5874`로 전 브랜치 대비 열세,
  7-branch 편입 시 `0.6195`(−0.0070), SMAD4 `0.4298`(−0.1149).
- **경계 안(저촉)**: 군집 병목을 우회해 원천 패치 임베딩 간 유사도로 직접 증거를 만들고 극값
  풀링하는 구조.
- **경계 밖(비저촉)**: 슬라이드 내부 통계를 거쳐 산출된 살리언스 재가중(`DS`). DS는 공통
  군집 중심 기준의 거시 분포를 쓰므로 염색 교란이 평균화된다.
- **재개 조건**: 염색 정규화(stain normalization)가 전처리에 도입되는 경우.

### `CA-06` 라벨 사용 판별 기저 (Fisher subspace) — §202

- **기각 기전**: `N_slides ≈ 40 ≪ D = 1536`에서 표본 라벨 차이 벡터는 질병 형태가 아니라
  **표본에 우연히 포함된 염색·스캐너·환자 노이즈를 분리 방향으로 오인**한다. macro
  `0.6265 → 0.5709`(−0.0556, 6/7 하락), 전 피처 브랜치가 동반 붕괴했다.
- **경계 안(저촉)**: Context 라벨로 **기저(basis) 자체를 회전·선택**하는 모든 방식.
- **경계 밖(비저촉)**: 기저는 무감독(within-slide PCA)으로 두고 **readout 단에서만** 라벨을
  쓰는 것. 현행 Dual Ridge가 그것이다.
- **재개 조건**: `N_ctx`가 수백 규모로 커지는 벤치마크가 도입되는 경우.

### `CA-07` In-Episode Context LOO 가중 — §212 · §221

- **기각 기전**: §212에서 ρ = −0.27로 폐기했고, §221에서 **용량 편향을 제거해도 회복되지
  않음**을 확인했다. ρ(특징 차원, LOO 팽창) = +0.667로 용량 진단 자체는 맞았으나, 무편향
  8D SHJ에서도 fold 수준 ρ = −0.091이었다. **원인은 낙관 편향이 아니라 context↔query 분포
  이동**이다.
- **경계 안(저촉)**: 에피소드 내 context LOO 점수를 브랜치·과제·강도의 **선택 신호나
  가중치**로 쓰는 모든 방식.
- **경계 밖(비저촉)**: LOO 마진을 **진단용으로 기록·분석**하는 것.
- **재개 조건**: context↔query 분포 이동을 직접 교정하는 수단이 확립되는 경우.
  (분포 이동 자체는 §215 SMAD4 역전과 같은 축이며, 여전히 미해결이다.)

### `CA-08` 집계 함수 변형 탐색 — §214-V

- **기각 기전**: 집계 방식 **8종**과 브랜치 부분집합 **31종** 전수에서 sign agreement 5/7
  도달이 **0건**이었다. 모든 변화량이 분해능 하한(±1.0%p) 아래에 있었다.
  ([`PROJECT.md` §4.1](PROJECT.md) 참조)
- **경계 안(저촉)**: **이미 산출된 브랜치 확률·마진 벡터 위에서** 결합 함수를 바꾸는 탐색
  (가중 평균, 적응적 절사, 게이팅, 순위 결합 등).
- **경계 밖(비저촉)**: **새로운 브랜치를 추가**해 입력 벡터 자체를 바꾸는 것. 그것은
  [`PROJECT.md` §5](PROJECT.md)의 채택 게이트가 다룬다.
- **재개 조건**: 분해능 하한이 개선되는 평가 체계가 확립되는 경우.
- **경계 미확정 → §3-A 참조**: 브랜치 **내부**에서 여러 강도/변형을 만들어 결합하는 구조가
  "집계 함수 변형"인지 "새 브랜치"인지.

### `CA-09` 평균의 새로운 사영·재가중 브랜치 — §217

- **기각 기전**: `BM`(사영) · `QA`(분위수) · `DS`(살리언스 재가중) · `RM`(꼬리 사영)이
  **모두 한 계열로 수렴**했다. 위치(Location) 계열의 상호 상관은 0.25~0.93이고,
  `BM`·`QA`·`DS` 셋의 유효 랭크는 `1.29 / 3`이다. `RM`은 max |r| = 0.690으로 게이트 ①
  탈락했고, 그 원인은 `CV`가 256차원 투영 공간 **전체**의 공분산이라 꼬리 부분공간을 이미
  읽고 있었기 때문이다.
- **경계 안(저촉)**: 슬라이드 1차 모멘트(평균)를 다시 사영·재가중·필터링해 새 브랜치를 만드는 것.
- **경계 밖(비저촉)**: **형상(Shape) 계열** — 위치와 무관한 통계(슬라이드 내 이질성, 모드 수,
  분포 기하, 국소 내재차원 등). 현 형상 계열은 `BD`·`SH`·`SHJ` 3개이며, 이 방향이 유효 랭크를
  올릴 수 있는 유일한 경로로 §217·§218이 지목했다.
- **재개 조건**: `CV`가 읽는 투영 공간의 정의가 바뀌어, 위치 계열이 게이트 ①(상관 상한,
  [`PROJECT.md` §5](PROJECT.md))을 통과할 수 있게 되는 경우.
- **경계 미확정 → §3-B 참조**: 평행이동 불변 차분을 쓰지만 계산이 재가중 평균의 사다리인 구조.

### `CA-10` 형상통계 강화 변형 — §219

- **기각 기전**: SH 강화 7종을 한 번에 실측해 가설 3건이 반증됐다. 차원 확대·로버스트화·
  왜도/첨도 분리 어느 것도 게이트 ②를 통과시키지 못했다. 부수 산출로 **신규 직교 브랜치가
  우선 절사된다는 통념도 반증**됐다(7-branch에서 `BS` 22.3% / `SH` 22.3%로 균등 기대 28.6%
  **미만**). §218이 내린 결론은 형상 계열의 병목이 절사가 아니라 **정보량**이라는 것이다.
- **경계 안(저촉)**: `SH`의 모멘트 정의를 변주하는 것(차수 추가, 로버스트 추정량 교체,
  성분 분리).
- **경계 밖(비저촉)**: `shj.py`가 `whitened.norm(dim=1)`로 32D 구름을 1차원 반경으로 붕괴시키며
  **버리는 성분**을 읽는 것 — 각도, 모드 수, 국소 내재차원 등. §226의 Tier 1
  (`AKS`·`MDX`·`LID`)이 이 영역이다.
- **재개 조건**: 없음. 정보량 병목이 해소되는 별도 근거가 필요하다.

### `CA-11` draw 안정성(ICC) 선택 신호 — §225

- **기각 기전**: ICC가 모든 subsampling 강도에서 0.9996~1.0000으로 **판별력이 전혀 없었다.**
  draw를 평균하는 구조상 남은 패치가 수백 개면 어떤 강도에서도 일치한다.
- **경계 안(저촉)**: draw 간 일치도를 과제별 강도·구성 선택의 신호로 쓰는 것.
- **경계 밖(비저촉)**: ICC를 **구현 정확성 검증**에 쓰는 것.
- **재개 조건**: 없음(구조적 이유로 닫힘).

### `CA-12` 에피소드 형상 축 — §114 · RU-36

- **기각 기전**: v88 PA 기각과 v89~v93 에피소드 형상·세포 축 소진. 합성 cell과 실제 cell의
  분포 격차가 원인으로 규명됐다.
- **경계 안(저촉)**: 에피소드 구성(형상·세포 축)을 바꿔 성능을 올리려는 시도.
- **경계 밖(비저촉)**: 평가 fold 구성은 §3.1에 따라 **고정**이므로 애초에 변경 대상이 아니다.
- **재개 조건**: 없음.

### `CA-13` 외부 Retrieval 계층 — §22 · RU-07

- **기각 기전**: retrieval 3대 가설이 전면 반증됐고 ICI 규모에서 이득이 없었다. O(N) 비용
  대비 통계적 혜택이 확인되지 않아 v22에서 계층을 영구 제거했다.
- **경계 안(저촉)**: 에피소드 밖 외부 풀에서 이웃을 검색해 context를 보강하는 구조.
- **경계 밖(비저촉)**: 에피소드 **내부** context 슬라이드만 쓰는 모든 연산.
- **재개 조건**: 후보 풀이 현재보다 훨씬 크거나 noisy donor 배제가 필요한 설정이 도입되는 경우.

### `CA-14` 학습 파라미터 기반 readout/head — §139 · RU-38

- **기각 기전**: 수백 에포크 GPU 분산 학습보다 within-context PCA + closed-form ridge가
  일반화와 OOD에서 **월등**했다. 학습 파라미터 P를 제거하고 고정 head로 전환한 v106이
  학습 계보를 대체했다.
- **경계 안(저촉)**: 경사하강으로 학습되는 파라미터를 활성 경로에 되돌리는 것.
  현행 baseline의 정의(학습 파라미터 0개, seed std 0.00000)를 깨뜨린다.
- **경계 밖(비저촉)**: fold context로부터 **닫힌 형태로 풀리는** 계수(Dual Ridge 해 등).
- **재개 조건**: 사용자의 명시적 결정. 프로젝트 정체성([`PROJECT.md` §1](PROJECT.md))에 해당하므로
  통상 연구 판단으로 열지 않는다.

### `CA-R1` Salience Anchor Subsampling — §223 종료 → **§225 철회** · 현재 `REOPENED`

- **경과**: §213이 "+7.65%p 폭등"으로 기록했으나 §223에서 **비교 baseline이 §212의 v120
  6-branch였던 오배치**로 밝혀져 실제 효과는 +0.43%p였고 축을 종료했다. §225의 강도 스윕이
  **실재하는 단조 용량반응**(|ρ| = 1.000, 4개 과제)을 확인해 **종료 판정을 철회**했다.
  기법이 무효였던 것이 아니라 §213의 설정이 너무 약했다.
- **현재 상태**: 열려 있으나 **활용 불가**. 이득이 전역이 아니라 과제별이고
  (ARID1A +2.97%p vs PBRM1 −6.64%p), 과제별 강도를 고를 **선택 신호가 없다.**
  신호 A(짝지은 context LOO)·B(draw 안정성, `CA-11`)·C(살리언스 집중도)가 모두 기각됐고,
  Context LOO 일반은 `CA-07`로 닫혔다.
- **재개 조건 (해소해야 할 것)**: 라벨 없이 과제를 판별하는 선택 신호. 이는 §221 SHJ 교착과
  **동일 구조**이며 현재 프로젝트의 대표 미해결 문제다.
