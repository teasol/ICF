검사 대상 자체가 소멸했다(스크린 경로가 없다). 재설계의 대상은 **귀속(attribution)** 이다.

## 1. 검사가 검증하는 것 / 검증하지 않는 것

| | 내용 |
|:--|:--|
| **검증한다 (L1)** | 저장된 예측이 선언된 구성(config·branch list·가중치·코드 해시·fold manifest)에 **귀속되는가** |
| **검증한다 (L2)** | 같은 기계·같은 디바이스에서 재실행이 동일 구성을 재현하는가(현행 closed-form 한정) |
| **검증하지 않는다** | 시점 간·기계 간 **수치 드리프트**. 값 앵커가 갖던 이 능력은 **상실**되며 공백으로 명시한다 |
| **검증하지 않는다** | 결론의 재현성. `D-048` 이후 학습 파라미터 후보에는 결정론이 성립하지 않는다 |

값 앵커의 "교체"가 아니다. **다른 검사**이며 드리프트 검출 능력은 상실됐다(`D-050`).

## 2. L1 — 귀속 검사

대조 대상 provenance 필드: `branch_list` · `weights` · `aggregation` · `sketch_dim` ·
`config_sha256` · `code_hash` · `git_commit` · `manifest_hash` · `data_version` · `env`.

판정:
- `provenance` 부재 → 실패.
- `config_sha256`가 기대 config 집합에 없음 → 실패.
- `branch_list`가 기대 config의 선언 브랜치와 다름 → 실패.
- `manifest_hash`가 비었거나 fold 파일 내용과 다름 → 실패.

## 3. L2 — 같은 기계 재현 (현행 closed-form 한정)

- 고정 프로브: `cptac_pda/SMAD4_mutation` fold 10, 5-branch.
- 같은 기계·디바이스에서 재실행한 fold-mean AUROC이 기존 기록과 **4자리 동일**이어야 한다.
- 이 조건은 closed-form 후보에만 적용한다. 학습 파라미터 후보에는 적용하지 않는다(`D-048`).
- 기계 간 허용 오차는 도입하지 않는다(`D-057`).

## 4. 양성·음성 대조 (사전 선언)

- **음성 대조**: 같은 구성 재실행 → L1 통과 + L2 4자리 동일. (L1만으로는 항진명제에
  가까우므로 L2를 함께 둔다.)
- **양성 대조**: 의도적으로 다른 config(7-branch, `d8c8ae4dca9b8ecf`)를 5-branch 기대 집합과
  대조 → L1 **실패해야** 한다.
- 양성 대조 통과는 **검출 민감도의 하한 확인**으로만 판정하고 오염 검출의 증명으로 쓰지 않는다.

## 5. D-053 계열 실패 검출

- 러너가 config를 조용히 치환하면 저장 산출물의 `config_sha256`이 선언과 달라져 L1이 잡는다.
- 감싸는 러너가 치환하지 않음을 전제하지 않고, 산출물의 `config_sha256`을 **선언 config
  파일 해시와 직접 대조**한다.

- 시점 간 수치 드리프트(값 앵커의 옛 능력)는 **검출하지 못한다.** 과거 측 비교 대상이
