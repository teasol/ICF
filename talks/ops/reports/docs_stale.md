# docs/ · talks/reports/ 낡은 서술 인벤토리

**목적**: 2026-09-18 하루 동안 뒤집힌 계측 진단(`D-053`, `RU-90` §9\~§10, arm parity) 이후,
`docs/` 와 `talks/reports/` 의 나머지 문서가 아직 담고 있는 **철회된 결론·낡은 전제**를 찾는다.
**문서는 하나도 수정하지 않았다.** 이 보고서 하나만 새로 쓴다.

**읽은 정본(가장 새로운 사실)**

- `docs/current_status.md`
- `talks/reports/2026-09-18_ru90_baseline_regen.md` §9\~§10
- `talks/reports/2026-09-18_arm_parity.md`
- `talks/reports/2026-09-18_branch_redundancy.md`
- `talks/reports/2026-09-18_foldfit_cost.md` §보강
- `docs/history/archive.md` `D-053`

**정본이 확정한 다섯 사실**

1. 여섯 실행 러너(`eval_v120` `eval_v121` `eval_ct_alone` `eval_ds_aug` `run_v120_clean_loo_experiments`
   `run_v121_salience_anchor`)는 **전부 같은 7-branch 설정으로 수렴**했다. arm 이름이 다른 실행들이
   서로 다른 구성을 돌린 적이 없다 (`D-053`, `RU-90` §10).
2. `src/` 는 환경변수를 하나도 읽지 않는다. `ICF_*` export 는 평가 코드에 **도달하지 않는다**
   (`RU-90` §8\~§9).
3. **YAML 경로는 정상이다.** `v121_7branch_active.yaml` 은 정확히 파싱되고, 공식 7-branch 재현은
   이미 성공했다(macro `0.6226` vs 공식 `0.6227`). "설정 표면 전체가 무효"도 "브랜치 집합을
   통제하는 경로 자체가 무효"도 틀렸다 (`RU-90` §9, `D-053`).
4. 과거 **arm 간 차이 보고는 구성 차이가 없는 실행들의 비교**이며, 거기서 나온 차이는 적합 변동이다
   (`D-053`, `RU-90` §10). 5-branch 대 7-branch의 첫 실제 비교는 **판별 불가**다 — 과제 군집 95% CI
   `[-0.0114, +0.0228]`가 0을 포함하고 7개 중 3개가 악화된다 (`arm_parity`).
5. fold 적합 1회는 **`20.0`초**(과제 3개 평균, 5-branch)다. 한 arm Primary 7 `1.94` GPU-hour,
   2 arm paired `3.89` GPU-hour(예산 4h의 97%), `R=4` 2×2 `31.1`(7.8배). **4 GPU-hour로 확증
   프로브는 불가능하다** (`foldfit_cost` §보강).

**심각도 정의**

- `철회 필요`: 현재 사실과 정면으로 어긋나 그대로 두면 오판을 유발한다.
- `보강 필요`: 핵심 전제·수치가 낡아 인용하면 계획이 틀어진다. 정정·한정 문구가 필요하다.
- `표현만 낡음`: 결론은 유효하나 표기·참조가 현행과 맞지 않는다.
