문서 사이에 **같은 수치가 여러 곳에 적혀 있는 곳**을 찾아 보고하라. **고치지 마라.**

배경: 이 저장소에는 "수치는 docs/PROJECT.md 에서만 선언하고 나머지는 링크한다"는 규칙이
있다. README 가 0.6265 를, handoff 가 0.6171 을 각각 다르게 적던 drift 를 막기 위한
규칙이다. 규칙이 지켜지고 있는지 아무도 훑어본 적이 없다.

대상: docs/**/*.md 와 talks/**/*.md 전부.

찾을 것: 아래 성격의 수치가 docs/PROJECT.md 바깥에 **선언처럼** 적힌 곳.
- AUROC 값 (0.6 ~ 0.8 대의 소수 4자리)
- 승격 임계값, 게이트 기준값
- 유효 랭크, 상관 임계값
- 예산 (GPU-hour), fold 수, 과제 수

**구분해야 할 것**: 보고서(talks/reports/)가 자기가 실측한 값을 적는 것은 중복이 아니다.
그것이 그 값의 출처다. 문제는 **다른 곳의 값을 옮겨 적은** 경우다. 어느 쪽인지 판단이
서지 않으면 `판단 불가`로 적어라.

보고 형식: `talks/ops/reports/docs_numbers.md`. 항목마다:
- 수치
- 어느 파일들에 나오는가 (파일:줄번호)
- 값이 서로 **일치하는가 어긋나는가**. 어긋나면 그것이 가장 중요하다
- 출처로 보이는 곳은 어디인가

**절대 하지 말 것**: 문서 수정. 보고서 하나만 쓴다.
어긋나는 값을 찾으면 그것을 보고서 맨 위에 따로 모아라.
