저장소 전체에서 **기계적으로 안전한 정리**만 수행하라.

대상: scripts/**/*.py, src/**/*.py, tests/**/*.py

고칠 것 (이것만):
1. 사용되지 않는 import 제거
2. 할당했으나 한 번도 읽지 않는 지역 변수 제거 (단, 반환값을 버리는 호출은 남겨라 —
   부작용이 있을 수 있다)
3. 치환자가 없는 f-string 의 f 접두사 제거 (`f"고정 문자열"` -> `"고정 문자열"`)
4. 같은 이름을 두 번 import 하는 중복 import 제거
5. 파일 끝의 공백 줄과 줄 끝 공백 제거

**절대 하지 말 것**:
- 로직 변경. 조건식, 계산식, 수치, 반복 순서를 건드리지 마라
- 주석·독스트링·타입 힌트 삭제나 수정. 이 저장소의 주석은 왜 그렇게 짜여 있는지를
  기록한 것이라 코드보다 중요할 때가 많다
- 함수/변수 이름 변경, 함수 분리나 병합
- 포매팅 일괄 적용 (black/isort 류 금지). 줄바꿈 위치를 바꾸지 마라
- `src/models/` 안의 수치 계산 경로 수정. 이 디렉터리는 import 정리와 5번 외에는
  손대지 마라. 결과가 1비트라도 달라지면 안 된다

검증 (반드시 수행):
- 수정한 파일마다 `python -m py_compile <파일>` 을 실행해 통과를 확인하라
- 마지막에 `.venv/bin/python -m pytest tests/ -q` 를 실행하고 결과를 보고하라.
  실패가 늘었다면 네 수정을 되돌려라

보고: 파일별로 무엇을 지웠는지 한 줄씩. 지운 것이 없으면 없다고 말하라.
확신이 없으면 그대로 두어라.
